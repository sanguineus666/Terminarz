# Changelog

## 1.0.1 — 2026-08-16

- dodano GitHub Actions workflow `Zbuduj APK`, uruchamiany ręcznie lub po pushu,
- build w chmurze używa JDK 17, Gradle 9.5.0, Android SDK 37 i Build Tools 36.0.0,
- przed zbudowaniem APK uruchamiane są testy jednostkowe,
- gotowy APK jest publikowany jako artefakt `KontrolaDostaw-APK`,
- dodano polską instrukcję `BUILD_Z_TELEFONU.md`,
- wyłączono automatyczny backup Androida dla danych biznesowych,
- podniesiono wersję aplikacji do 1.0.1 / versionCode 2.
